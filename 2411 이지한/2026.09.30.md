# 2026.09.30.

이번 주는 앱 팀과 서버 팀이 서로 다르게 이해하는 일이 없도록 API 문서를 제대로 정리하고, 개발 일정을 짜는 데 집중했다.

## 일주일 동안 내가 만들어 낸 것

팀원이 쓴 API 문서가 ERD나 디자인 시안이랑 안 맞는 부분이 있어서 하나씩 비교하면서 고쳤다. 그렇게 정리한 걸 API 명세서로 만들었는데, 전체 96개 중에 이번에 꼭 만들 MVP는 35개다. 팀원들이 쉽게 볼 수 있게 검색되는 문서 페이지도 만들어서 링크로 공유했다.

개발 일정도 새로 짰다. 9/30에 시작해서 11/3에 제출하는 걸로 잡았고, 해야 할 작업 116개를 일주일 단위로 나눠서 누가 언제까지 뭘 하는지 볼 수 있게 했다. 디자인은 홈 화면과 프로필 화면을 고치고 다크 모드도 만들었다. 운동 종목을 직접 고르는 화면도 새로 추가했다. 백엔드는 사용자 엔티티 5개를 만들어서 깃허브에 올렸고, 팀원이 올린 수정 내용도 받아서 확인했다.

## 일주일 동안 겪었던 힘든 점, 극복했다면 해결 방법

이번 주에도 같은 내용을 서로 다르게 알고 있는 게 문제였다. 예를 들어 분석 결과를 바로 보여줄지 잠깐 기다렸다가 보여줄지, 운동 기록을 종목별로 저장할지, AI가 세트 수까지 정해줄지를 사람마다 다르게 알고 있었다. 이런 건 문서에 "정해야 할 것" 목록으로 따로 적어서 팀원들이 하나씩 정하기로 했다.

일정이 너무 빡빡한 것도 걱정이다. 시작이 하루 늦어져서 제출일(11/3)과 중간발표(11/4) 사이가 하루밖에 안 남았다. 그래서 매주 실제로 얼마나 했는지 적어보고, 늦어지면 어떤 기능부터 뺄지 순서를 미리 정해뒀다. 소셜 로그인이랑 목표 사진을 저장할지 같은 건 아직 팀에서 못 정했다.

## 내가 잘한 것과 더 잘할 수 있었는데 아쉬웠던 점

앱이랑 서버가 같은 문서를 보고 개발할 수 있게 만든 건 잘한 것 같다. 아쉬운 건 아직 못 정한 것들이 남아 있는데 일정부터 짜서 시작한 거다. 10/3까지 팀원들이랑 회의해서 못 정하면 앱이랑 서버가 또 어긋날 수 있다.

## 다음주까지 할 것

10/1까지 API 문서를 팀원들이랑 같이 확인해서 확정하고, 10/3까지 목표 사진을 저장할지 정한다. 10/4에는 문서를 더 이상 바꾸지 않게 고정할 계획이다. 그리고 팀 깃허브에 작업 목록을 올려서 첫 주 작업을 시작하고, 각자 실제로 몇 시간 했는지 적어서 계획이랑 비교해볼 것이다.
