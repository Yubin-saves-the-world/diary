## 2026.08.26.

일단 이번 주는 기획에 집중했다. 기획을 더 완벽하게 만들려고 기획서 양식부터 만들고 팀원들과 회의한 뒤에 기획서를 작성했다. 그러고 나서 디자인을 구상했다. 와이어프레임을 먼저 만들어 놓고 그걸 AI로 보정해서, 산학기업에 보여줄 때 우리가 뭘 만들려는 건지 쉽고 확실하게 알 수 있게 했다.

### 일주일 동안 내가 만들어 낸 것

기획서를 작성했다. 프로젝트 개요랑 주제를 고른 이유, 비슷한 앱들을 조사한 내용, 주요 기능 8가지, 화면 구성, 사용할 기술과 역할 분담까지 넣었다. 그리고 화면을 직접 그려본 다음 AI로 보정해서 시안 9개를 만들었다. 기술은 앱은 Flutter, 서버는 Spring Boot, DB는 MySQL로 정했고 체형 분석은 MediaPipe Pose를 쓰기로 했다. 자세를 인식하는 모델이 여러 개라서 뭐가 우리한테 맞는지 찾아보는 데 시간을 좀 썼다.

### 일주일 동안 겪었던 힘든 점, 극복했다면 해결 방법

지금은 초반이어서 팀원들 간의 관계도 원만하고 그 밖에 어려웠던 점은 없었다. 굳이 꼽자면 목표 체형 사진을 어떻게 분석에 쓸지가 계속 걸렸다. 사진 두 장을 비교한다는 게 생각보다 간단하지 않았다. 그래서 처음부터 다 하려고 하지 말고, 목표 사진에서 부위별로 얼마나 발달했는지만 뽑아서 지금 몸이랑 비교하는 정도로 줄이기로 했다.

### 내가 잘한 것과 더 잘할 수 있었는데 아쉬웠던 점

기획서를 양식부터 만들어서 팀원들이 각자 뭘 채워야 하는지 헷갈리지 않았던 건 잘한 것 같다. 아쉬운 건 조금만 더 노력해서 기능명세서까지 썼어야 했는데 학교 나의 와이파이가 원활하지 못하여 작성하지 못했다.

### 다음주까지 해올 것

기획의 틀을 마련했으니 API 명세서랑 ERD 다이어그램, 기능명세서를 작성해서 개발 환경 세팅이랑 전반적인 준비 과정을 해놓을 거다.
