## 2026.11.04.

이번 주는 체형 분석 결과를 저장하는 API를 만들어보는 데 집중했다. 앞에서 정리해둔 ERD랑 API 명세서를 보면서 분석 결과가 어떤 형태로 들어와야 하는지 다시 확인하고, 그걸 기준으로 저장 부분부터 구현해봤다.

### 일주일 동안 내가 만들어 낸 것

분석 결과 저장 API를 만들었다. 프론트에서 부위별 점수로 가공해서 보내주면 서버에서 분석 결과랑 부위별 발달도 테이블에 나눠서 저장하는 구조다. 저장된 기록을 날짜순으로 불러오는 조회 API도 간단하게 만들어봤다.

### 일주일 동안 겪었던 힘든 점, 극복했다면 해결 방법

부위별 점수가 여러 개 같이 들어가다 보니 중간에 하나가 저장이 안 되면 데이터가 반쯤만 들어가는 문제가 있었다. 처음엔 이유를 몰라서 좀 헤맸는데, 저장하는 부분을 하나의 트랜잭션으로 묶어서 실패하면 다 같이 롤백되게 바꿔서 해결했다.

### 내가 잘한 것과 더 잘할 수 있었는데 아쉬웠던 점

명세서랑 비교하면서 응답 형식을 맞춘 건 잘한 것 같다. 아쉬운 점은 테스트를 Postman으로 하나하나 해보느라 생각보다 시간이 오래 걸렸다는 거다.

### 다음주까지 해올 것

발표자료를 준비하고, 팀원들이랑 맡을 부분을 나눠서 발표 연습도 해볼 예정이다.
