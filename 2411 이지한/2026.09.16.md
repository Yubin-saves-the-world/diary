# 2026.09.16.

이번 주는 지난주에 잡아둔 기획을 실제로 개발할 수 있는 형태로 옮기는 데 집중했다. ERD를 다시 손보고, 그걸 바탕으로 기능명세서를 쓰고, 백엔드 프로젝트 초기 세팅을 해뒀다. 화면 쪽도 지난주 시안에서 빠졌던 부분들을 피그마에서 채워 넣었다.

## 일주일 동안 내가 만들어 낸 것

ERD 다이어그램을 다시 정리했다. 테이블 간 관계가 애매했던 부분을 손봐서 데이터가 겹치거나 빠지지 않게 만들었다. 그걸 바탕으로 기능명세서를 새로 썼는데, 지난주엔 기능 이름만 나열했다면 이번엔 화면별로 어떻게 동작하는지까지 정리했다. 그리고 백엔드 프로젝트 초기 세팅을 마쳐서 이제 바로 개발을 시작할 수 있는 상태로 만들어뒀다. 피그마도 손봐서 화면 전체에 통일감을 주고, 빠져 있던 부분들을 채워 넣었다.

## 일주일 동안 겪었던 힘든 점, 극복했다면 해결 방법

이번 주는 작업량보다 팀원들 간의 소통이 안 된 게 더 힘들었다. 각자 맡은 부분을 따로 진행하다 보니 누가 뭘 언제까지 하는지 서로 잘 모르는 채로 넘어간 부분이 있었고, 그러다 보니 같은 내용을 다르게 이해해서 의견이 부딪히는 일도 있었다. 아직 완전히 해결됐다고 하기는 어렵지만, 다음 주부터는 개발 일정을 문서로 만들어서 누가 언제까지 뭘 하는지 눈에 보이게 정리하기로 했다.

## 내가 잘한 것과 더 잘할 수 있었는데 아쉬웠던 점

기능명세서를 화면별 동작까지 구체적으로 써둔 건 잘한 것 같다. 아쉬운 건 팀원들과의 소통이었다. 진행 상황을 더 자주 공유했어야 했는데 그러지 못해서 갈등이 생긴 게 이번 주 제일 아쉬운 부분이다.

## 다음주까지 할 것

이번 주 중으로 개발 일정을 확립하고, 다음 주 목요일까지 백엔드 API 명세서를 작성한다. 가능하면 이번 주 안에 프론트엔드 개발도 착수할 수 있도록 준비해둘 계획이다.
