# 2026.10.07.

이번 주는 ERD를 기준으로 백엔드 Entity를 전부 작성하고, 작성한 Entity가 실제 DB와 맞는지 검토하는 데 집중했다.

## 일주일 동안 내가 만들어 낸 것

### Entity 작성
- ERD 다이어그램을 참고해서 Entity를 모두 작성했다.
- 지난주에 올린 사용자 Entity 5개도 새로만든 ERD 기준으로 다시 맞췄다.
- 전체 컬럼은 275개, 테이블 사이의 연결(FK)은 49개다.

### Entity 검토
- 실제 MySQL에 연결해서 테이블 구조와 Entity가 하나씩 일치하는지 확인했다.


## 일주일 동안 겪었던 힘든 점, 극복했다면 해결 방법

### 어려웠던 점
- Entity가 개수가 많아서 ERD와 코드가 조금씩 어긋날 위험이 컸다.

### 해결 방법
- ERD 원본에서 Entity 코드를 만들어 내고, 만든 코드를 실제 DB에 붙여서 어긋나는 곳을 바로 찾았다.

### 아직 못 정한 것
- 탈퇴한 사용자의 글과 동의 기록을 얼마나 보관할지

## 내가 잘한 것과 더 잘할 수 있었는데 아쉬웠던 점

### 잘한 것
- ERD와 Entity가 같은 원본에서 나오게 만들고 실제 DB로 검증했다.
- 이제 DB가 바뀌어도 코드를 같이 맞출 수 있다.

### 아쉬운 점
- Entity를 다 만든 뒤에야 검토를 시작해서, 팀원과 중간에 한 번 맞춰 보지 못했다.
