## 일주일 동안 내가 만들어 낸 것

마이페이지, 체형 분석·분석 기록, 커뮤니티, AI 코치와 홈 연동 화면을 구현하고 로그인·회원가입·비밀번호 찾기 기능을 보완했습니다.

주간 반복 일정과 휴식일 설정, 추천 루틴 적용, 운동 기록·통계, 프로필 수정, 게시글·댓글·좋아요·신고·차단 기능을 구현했습니다.

식단·상품·미션·쿠폰·알림 설정 등 추가 화면과 API 연결 코드를 작성하고, 앱 로고·시작 화면 및 전체 UI를 정리했습니다.

## 일주일 동안 겪었던 힘든 점과 해결 방법

기획서와 실제 백엔드 API가 다른 부분이 있어 문서, 코드, 응답 예시를 비교하며 연결 방식을 조정했습니다.

분석 실패와 응답 지연에 대응하는 재시도 처리를 추가하고, 화면 테스트로 작은 화면에서의 배치 문제를 확인했습니다.

## 내가 잘한 것과 더 잘할 수 있었는데 아쉬웠던 점

기존 기능을 유지하면서 구현 범위를 넓히고, 버튼·아이콘·색상·간격을 통일해 화면의 완성도를 높였습니다.

다만 실제 서버와 AI 연결 상태에 제약이 있어 전체 가입·분석·추천 흐름을 실환경에서 끝까지 검증하지 못한 점이 아쉬웠습니다.
