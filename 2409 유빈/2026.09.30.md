또한 기존 기획 내용을 다시 확인하면서 기획서, ERD, API 명세서에서 부족하거나 맞지 않는 부분을 찾아 수정하고 보완했습니다. 이를 통해 이후 개발 과정에서 문제가 생길 수 있는 부분을 미리 정리했습니다

## 일주일 동안 겪었던 힘든 점과 해결 방법

이번 주에는 디자인을 수정하는 과정에서 배치, 폰트 크기와 굵기 등 세부적인 요소를 조정하는 데 어려움이 있었습니다.

또한 본격적인 개발에 들어가기 위해 기획서, ERD, API 명세서 등을 다시 확인하는 과정에서 생각보다 많은 문제점과 수정할 부분이 발견되어 전체적으로 복잡하고 힘들었습니다. 발견된 문제들은 하나씩 확인하면서 팀원들과 수정 방향을 정하고 보완해 나갔습니다.

## 내가 잘한 것과 더 잘할 수 있었는데 아쉬웠던 점

디자인을 대부분 수정하고, 기획서와 ERD, API 명세서까지 다시 점검하면서 프로젝트의 문제점을 미리 찾아 보완한 점은 잘했다고 생각합니다.

다만 본격적인 개발에 들어가기 전에 수정해야 할 부분이 생각보다 많이 발견되어 진행이 조금 늦어진 점은 아쉬웠습니다. 처음 기획 단계에서 세부적인 부분까지 더 꼼꼼하게 확인했다면 이후 수정해야 할 내용을 줄일 수 있었을 것 같습니다.
