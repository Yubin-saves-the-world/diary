# 캡스톤 프로젝트 일지

**팀명:** 유빈이가 세상을 구한다
**이름:** 유빈
**캡스톤 프로젝트 진행 날짜:** 2026.08.26.

## 일주일 동안 내가 만들어 낸 것

이번 주는 본격적인 개발에 들어가기 전, 팀원들과 함께 프로젝트 기획을 진행했습니다.

기능적인 부분에서는 **간편 로그인, 신체 검사, 커뮤니티 기능** 등에 대한 아이디어를 제안했습니다. 또한 페이지 구성에서는 각 페이지 간의 **연계성과 기능 배치**를 고려하여 사용자가 자연스럽게 서비스를 이용할 수 있도록 아이디어를 제시했습니다.

## 일주일 동안 겪었던 힘든 점과 해결 방법

이번 주는 아직 개발 단계에 들어가지 않았고, 기획 과정에서도 팀원들과 원활하게 소통하며 진행했기 때문에 특별히 힘들었던 점은 없었습니다.

서로의 의견을 공유하고 조율하면서 큰 문제 없이 기획을 진행할 수 있었습니다.

## 내가 잘한 것과 더 잘할 수 있었는데 아쉬웠던 점

기획 과정에서 **커뮤니티 기능에 대한 아이디어를 제안하고 실제 기획에 추가한 점**이 만족스러웠습니다.

다만 프로젝트에 도움이 될 수 있는 다양한 기능과 아이디어를 조금 더 적극적으로 생각하고 제안할 수 있었을 것 같은데, 그러지 못한 점은 아쉬웠습니다. 다음 기획 과정에서는 더 다양한 관점에서 아이디어를 생각해 보고 적극적으로 의견을 제시하고 싶습니다.

* 기획 발표용 PPT 제작
